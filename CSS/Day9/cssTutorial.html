Section 1 : CSS Selectors

Universal Selector (*)

The universal selector selects all elements present on a webpage. It is commonly used to remove default browser spacing and apply common styles to every element.

Example:

*{
    margin: 0;
    padding: 0;
}

Element Selector

The element selector targets HTML elements using their tag names. All matching elements receive the specified styles.

Example:

p{
    color: blue;
}

Class Selector (.classname)

The class selector selects elements using their class attribute. Multiple elements can share the same class name. This is one of the most commonly used selectors in CSS.

Example:

.card{
    background-color: lightblue;
}

ID Selector (#idname)

The ID selector targets a specific element using its unique id attribute. An ID should only be used once within a webpage.

Example:

#header{
    background-color: black;
}

Descendant Selector

The descendant selector targets elements that are placed inside another element. It is represented using a space between selectors.

Example:

.container p{
    color: red;
}

Child Selector (>)

The child selector targets only direct children of a parent element. Nested grandchildren or deeper elements are not selected.

Example:

.container > p{
    color: green;
}

Section 2 : CSS Specificity

What is Specificity?

Specificity is the rule used by browsers to determine which CSS style should be applied when multiple styles target the same element. The selector with higher specificity takes priority.

Priority Order:

Inline CSS
ID Selector
Class Selector
Element Selector

Specificity Example

If multiple selectors target the same element, the browser checks specificity values and applies the style with the highest priority.

Example:

#title{
    color: red;
}

.heading{
    color: blue;
}

h1{
    color: green;
}

The text color will be red because the ID selector has higher specificity than class and element selectors.

Section 3 : Typography

font-family

The font-family property defines the typeface used for displaying text. Different fonts create different visual appearances and improve readability.

Example:

p{
    font-family: Arial, sans-serif;
}

font-size

The font-size property controls the size of text displayed on a webpage. Larger values create bigger text while smaller values reduce text size.

Example:

h1{
    font-size: 32px;
}

font-weight

The font-weight property controls the thickness of text. Common values include normal, bold, and numeric values.

Example:

p{
    font-weight: bold;
}

text-align

The text-align property controls the horizontal alignment of text. Text can be aligned left, right, center, or justified.

Example:

h1{
    text-align: center;
}

text-transform

The text-transform property changes the capitalization style of text. It can convert text to uppercase, lowercase, or capitalize words.

Example:

h1{
    text-transform: uppercase;
}

line-height

The line-height property controls the vertical spacing between lines of text. Proper line spacing improves readability and visual appearance.

Example:

p{
    line-height: 1.8;
}

Section 4 : Size Properties

width

The width property defines the horizontal size of an element. It controls how much space an element occupies from left to right.

Example:

div{
    width: 300px;
}

height

The height property defines the vertical size of an element. It controls the amount of space occupied from top to bottom.

Example:

div{
    height: 200px;
}

min-width

The min-width property specifies the minimum width an element can have. The element will not shrink below this value.

Example:

div{
    min-width: 250px;
}

max-width

The max-width property specifies the maximum width an element can have. The element will not grow beyond this value.

Example:

div{
    max-width: 600px;
}

min-height

The min-height property defines the minimum height an element can have. It prevents the element from becoming too short.

Example:

div{
    min-height: 200px;
}

max-height

The max-height property defines the maximum height an element can have. It restricts excessive vertical growth.

Example:

div{
    max-height: 500px;
}

Section 5 : Box Model

What is the Box Model?

Every HTML element is treated as a rectangular box in CSS. The box model consists of Content, Padding, Border, and Margin. Understanding the box model is essential for creating layouts.

Structure:

     Margin
     Border
     Padding
     Content

Content

The content area contains the actual text, image, button, or any information displayed inside the element. Width and height properties directly affect this area.

Example:

div{
    width:300px;
    height:200px;
}

box-sizing

The box-sizing property determines how the width and height of an element are calculated. The border-box value includes padding and border inside the total size.

Example:

*{
    box-sizing:border-box;
}

Section 6 : Padding and Margin

Padding

Padding creates space between the content and the border. It increases the internal spacing of an element and improves readability.

Example:

.card{
    padding:20px;
}

Padding Directions

Padding can be applied individually to the top, right, bottom, and left sides of an element.

Example:

.card{
    padding-top:10px;
    padding-right:20px;
    padding-bottom:10px;
    padding-left:20px;
}

Margin

Margin creates space outside an element's border. It is used to separate elements from each other.

Example:

.card{
    margin:20px;
}

Margin Directions

Margin can also be applied individually to each side. This allows precise control over spacing between elements.

Example:

.card{
    margin-top:10px;
    margin-right:20px;
    margin-bottom:10px;
    margin-left:20px;
}

Section 7 : Border Properties

border

The border property creates a visible outline around an element. It requires a width, style, and color value.

Example:

.card{
    border:2px solid black;
}

border-width

The border-width property controls the thickness of the border surrounding an element.

Example:

.card{
    border-width:5px;
}

border-style

The border-style property determines the appearance of the border line. Common values include solid, dashed, and dotted.

Example:

.card{
    border-style:dashed;
}

border-radius

The border-radius property creates rounded corners. It is commonly used in cards, buttons, and modern UI designs.

Example:

.card{
    border-radius:10px;
}

Section 8 : Display Property

display: block

Block elements occupy the entire available width by default. They always start on a new line.

Example:

div{
    display:block;
}

display: inline

Inline elements only take up the space needed by their content. They do not start on a new line.

Example:

span{
    display:inline;
}

display: inline-block

Inline-block elements stay on the same line while still allowing width and height properties.

Example:

button{
    display:inline-block;
}

display: none

The none value completely hides an element from the webpage. The hidden element does not occupy any space.

Example:

.menu{
    display:none;
}

display: flex

The flex value activates the Flexbox layout system. It makes arranging elements easier and more responsive.

Example:

.container{
    display:flex;
}

display: grid

The grid value activates the CSS Grid layout system. It is used for creating complex two-dimensional layouts.

Example:

.container{
    display:grid;
}

Section 9 : Flexbox

display: flex

Flexbox is a one-dimensional layout system. It arranges items in rows or columns and makes alignment easier.

Example:

.container{
    display:flex;
}

flex-direction

The flex-direction property determines whether items are arranged horizontally or vertically.

Example:

.container{
    flex-direction:row;
}

justify-content

The justify-content property aligns items along the main axis. It is commonly used to control horizontal spacing.

Example:

.container{
    justify-content:center;
}

align-items

The align-items property aligns items along the cross axis. It is often used for vertical centering.

Example:

.container{
    align-items:center;
}

flex-wrap

The flex-wrap property allows items to move onto multiple lines when there is not enough space.

Example:

.container{
    flex-wrap:wrap;
}

gap

The gap property creates spacing between flex items. It provides cleaner layouts than using margins.

Example:

.container{
    gap:20px;
}

Section 10 : CSS Grid

display: grid

CSS Grid is a two-dimensional layout system used to arrange elements in rows and columns. It provides greater control over layouts compared to traditional methods.

Example:

.container{
    display:grid;
}

grid-template-columns

The grid-template-columns property defines the number and size of columns in a grid container.

Example:

.container{
    grid-template-columns:1fr 1fr 1fr;
}

grid-template-rows

The grid-template-rows property defines the height and number of rows inside a grid container.

Example:

.container{
    grid-template-rows:100px 100px;
}

gap

The gap property creates spacing between grid rows and columns. It helps maintain a clean and organized layout.

Example:

.container{
    gap:20px;
}

Section 11 : CSS Units

px (Pixels)

Pixels are fixed units of measurement. They provide precise control over the size of elements.

Example:

h1{
    font-size:32px;
}

% (Percentage)

Percentage units are relative to the size of the parent element. They are commonly used in responsive layouts.

Example:

div{
    width:50%;
}

rem

The rem unit is relative to the root element's font size. It provides consistent sizing throughout a webpage.

Example:

p{
    font-size:1.5rem;
}

em

The em unit is relative to the font size of the parent element. It is useful for creating scalable components.

Example:

p{
    font-size:1.5em;
}

vh (Viewport Height)

The vh unit represents a percentage of the browser window height. It is commonly used for full-screen sections.

Example:

section{
    height:100vh;
}

vw (Viewport Width)

The vw unit represents a percentage of the browser window width. It is useful for responsive designs.

Example:

section{
    width:100vw;
}

Section 12 : Background Properties

background-color

The background-color property sets the background color of an element. It is one of the most frequently used CSS properties.

Example:

div{
    background-color:lightblue;
}

background-image

The background-image property places an image behind the content of an element.

Example:

div{
    background-image:url("image.jpg");
}

background-repeat

The background-repeat property controls whether the background image repeats across the element.

Example:

div{
    background-repeat:no-repeat;
}

background-size

The background-size property controls the size of the background image. The cover value fills the entire container.

Example:

div{
    background-size:cover;
}

background-position

The background-position property controls the placement of a background image within an element.

Example:

div{
    background-position:center;
}

Section 13 : Position Properties

position: relative

Relative positioning moves an element from its original location. The element still occupies its original space in the layout.

Example:

.box{
    position:relative;
    top:20px;
}

position: absolute

Absolute positioning removes an element from the normal document flow. It is positioned relative to its nearest positioned ancestor.

Example:

.box{
    position:absolute;
    top:50px;
    left:50px;
}

position: fixed

Fixed positioned elements stay in the same location even when the webpage is scrolled.

Example:

.button{
    position:fixed;
    bottom:20px;
    right:20px;
}

position: sticky

Sticky positioning behaves like relative positioning until a specified scroll point is reached, then behaves like fixed positioning.

Example:

.navbar{
    position:sticky;
    top:0;
}

Section 14 : Pseudo Classes

:hover

The :hover pseudo-class applies styles when the user places the mouse pointer over an element. It is commonly used for buttons, cards, links, and navigation menus.

Example:

button:hover{
    background-color:black;
    color:white;
}

:active

The :active pseudo-class applies styles while an element is being clicked by the user.

Example:

button:active{
    transform:scale(0.95);
}

:focus

The :focus pseudo-class applies styles when an input field, textarea, or other interactive element receives focus.

Example:

input:focus{
    border:2px solid blue;
}

:first-child

The :first-child pseudo-class selects the first child element inside a parent element.

Example:

li:first-child{
    color:red;
}

:last-child

The :last-child pseudo-class selects the last child element inside a parent element.

Example:

li:last-child{
    color:green;
}

Section 15 : Transition and Animation

transition

The transition property creates smooth changes between different states of an element. It is commonly used with hover effects.

Example:

.card{
    transition:0.3s;
}

transition-duration

The transition-duration property specifies how long a transition effect should take to complete.

Example:

.card{
    transition-duration:1s;
}

transform

The transform property changes the appearance or position of an element without affecting surrounding elements.

Example:

.card:hover{
    transform:scale(1.1);
}

animation

The animation property applies a predefined keyframe animation to an element.

Example:

.box{
    animation:move 2s infinite;
}

Section 16 : Media Queries

What are Media Queries?

Media queries allow developers to apply different CSS rules based on screen size, device type, or viewport dimensions. They are essential for creating responsive websites.

Example:

@media(max-width:768px){

}

Responsive Text

Media queries can adjust font sizes for smaller devices, making content easier to read on mobile screens.

Example:

@media(max-width:768px){

    h1{
        font-size:24px;
    }

}

Responsive Layout

Media queries can change layout structures such as Flexbox and Grid to better fit smaller screens.

Example:

@media(max-width:768px){

    .container{
        flex-direction:column;
    }

}
